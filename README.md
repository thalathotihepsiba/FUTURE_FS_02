# 🚀 Client Lead Management System (Mini CRM)

> **Developed as part of the Future Interns – Full Stack Web Development Internship**

A full-stack **Client Lead Management System (Mini CRM)** built using **HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB**. This application enables businesses to collect, manage, and store customer lead information efficiently through a responsive web interface and a secure backend API.

---

# 📖 Project Overview

The **Client Lead Management System** is a simple yet practical CRM application that demonstrates the fundamentals of Full Stack Web Development.

Users can submit customer information through a responsive frontend. The backend processes the request using Express.js and stores the data securely in MongoDB using Mongoose.

The project showcases frontend development, backend API creation, database integration, and client-server communication.

---

# 🎯 Project Objective

Many small businesses still manage customer enquiries manually using notebooks or spreadsheets, making it difficult to organize and retrieve lead information.

This project provides a simple digital solution that helps businesses:

- Store customer lead information
- Organize client records
- Improve data management
- Demonstrate CRUD-based backend development
- Practice Full Stack Web Development concepts

# ⚙️ Installation Guide

### 1. Clone the Repository

```bash
git clone https://github.com/thalathotihepsiba/FUTURE_FS_02.git
```

### 2. Navigate to Backend

```bash
cd backend
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Create Environment Variables

Create a `.env` file and add:

```env
PORT=5000
MONGO_URI=Your_MongoDB_Connection_String
```

### 5. Start the Backend Server

```bash
npm start
```

### 6. Launch the Frontend

Open:

```
frontend/index.html
```

in your preferred web browser.
