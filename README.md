# Client Lead Management System (Mini CRM)

This project was developed as part of the **Future Interns – Full Stack Web Development Internship**.

## 📌 Project Overview

The Client Lead Management System is a simple Mini CRM that allows users to submit client details through a contact form. The backend stores lead information in a MongoDB database using Node.js, Express.js, and Mongoose.

## ✨ Features

- Responsive User Interface
- Client Lead Submission Form
- Backend API using Express.js
- MongoDB Database Integration
- Store Client Details
- Retrieve Client Leads
- REST API
- Easy to Use Interface

## 🛠 Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- CORS
- Dotenv

## 🚀 How to Run

1. Clone the repository

```
git clone https://github.com/thalathotihepsiba/FUTURE_FS_02.git
```

2. Go to the backend folder

```
cd backend
```

3. Install dependencies

```
npm install
```

4. Create a `.env` file

```
PORT=5000
MONGO_URI=Your_MongoDB_Connection_String
```

5. Start the server

```
npm start
```

6. Open the frontend in your browser.
